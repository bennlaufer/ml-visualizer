Almost every model learns the same way: three steps, on repeat

1

Predict

Use the function to guess every answer.

2

Assess predictions

How far were the predictions from the actual values?

3

Learn

Adjust the function so predictions are closer to actual values.

↻ Repeat until you are happy with the assessment
