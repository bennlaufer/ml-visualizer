# ML Visualizer

Interactive, story-driven lessons that teach machine learning ideas without heavy math.

## Lessons

- **[How models learn (intro)](https://bennlaufer.github.io/ml-visualizer/intro.html)** - the three steps every model repeats: predict, assess, learn. Watch a line learn house prices.
- **[Linear regression: The Realtor Story](https://bennlaufer.github.io/ml-visualizer/linear-regression.html)** - price houses by drawing a line, measure how wrong it is (mean squared error), then fix it step by step with gradient descent.

Each lesson is a single self-contained HTML file. Open it in any modern browser; no install or build step needed.

Live site: https://bennlaufer.github.io/ml-visualizer/
